# Nand2Tetris 🧠➡️🎮

Building a computer from scratch — from a single NAND gate to Tetris.

## 🔧 What’s here:
- Logic gates (HDL)
- ALU, Registers, RAM
- Hack Assembler
- VM Translator
- Jack Compiler
- Operating System
- Tetris 🎮

## 📘 Based on:
*The Elements of Computing Systems* by Nisan & Schocken  
[nand2tetris.org](https://www.nand2tetris.org/)

## 👨‍💻 Why?
To understand how computers work, end-to-end.
